# ByteVeil 字节帘

把任意文件用密钥打乱成无法直接读取的 `.bveil` 封包，并可用同一密钥完整还原。全部运算在浏览器本地完成，没有账号、服务器或网络请求。

## 直接使用

双击 **`ByteVeil.html`** 即可。它是单文件版本，HTML、CSS、JS 全部内嵌，可以单独复制给别人。

`index.html` 是开发版入口，依赖同目录下的 `styles.css`、`veil.js` 和 `app.js`。

## 使用方法

1. 打开 `ByteVeil.html`。
2. 把文件拖进窗口，或点击选择文件（任意格式）。
3. 输入密钥，再输入一次确认。可以点击“生成随机密钥”获得 28 位强随机密钥。
4. 点击“打乱并封包”，下载 `原文件名.bveil`。
5. 还原时切换到“还原文件”，放入 `.bveil` 封包，输入同一密钥，下载还原文件。

封包会按内容自动识别，不依赖扩展名；把 `.bveil` 改名也能被识别。

## 安全参数

- **内容加密**：AES-256-GCM，逐块认证。
- **密钥派生**：PBKDF2-SHA-256，310,000 次迭代，每个封包独立随机 salt。
- **随机 IV**：每个封包独立；每块使用唯一计数器派生 IV。
- **防篡改**：文件头、块序号、块总数都作为 GCM 附加认证数据；截断、重排、替换块都会被拒绝。
- **边界**：文件内容加密；原始文件名、大小和时间会保存在封包头中以便还原，并受完整性认证保护。
- **限制**：单文件上限 1 TiB；实际可处理大小受浏览器内存限制；非常大的文件建议先关闭其他标签页。

## 重要提醒

- **密钥无法找回。** 密钥不会上传、不会写入封包，也没有后门。丢失密钥等于丢失文件。
- 请用安全渠道把密钥交给接收方，不要和封包放在同一个地方。
- 建议至少 12 位密钥，或直接使用“生成随机密钥”。
- 页面依赖 Web Crypto，请使用较新的 Chrome、Edge、Firefox 或 Safari 直接打开本地文件。
- 单文件版本通过 CSP 哈希限制只运行内嵌脚本，且禁止任何网络连接。
